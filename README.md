# Portfólio — Samuel Damasceno Sales

Portfólio pessoal desenvolvido com Next.js para apresentar minha trajetória, formação acadêmica, interesses, habilidades técnicas e projetos desenvolvidos.

O projeto foi desenvolvido como parte do desafio de Front-End, com foco em responsividade, interatividade, organização de conteúdo e experiência do usuário.

## Sobre o projeto

O portfólio reúne informações sobre minha trajetória, formação, hobbies, conhecimentos técnicos e projetos pessoais em uma interface responsiva e interativa.

A aplicação foi construída utilizando Next.js, React e TypeScript, com componentes reutilizáveis, estilização personalizada e suporte aos temas claro e escuro.

## Seções

- **Sobre mim** — apresentação da minha trajetória e objetivos.
- **Hobbies** — interesses e atividades que fazem parte da minha rotina.
- **Formação acadêmica** — trajetória educacional e formação.
- **Experiências e projetos** — projetos pessoais e experiências práticas.
- **Stack** — tecnologias e ferramentas com as quais tenho experiência.
- **Contato** — informações para contato e redes profissionais.

## Como executar

### Pré-requisitos

- Node.js 18 ou superior
- npm ou pnpm

### Instalação

    git clone https://github.com/busaikuna/portfolio.git
    cd portfolio
    npm install

### Desenvolvimento

    npm run dev

A aplicação estará disponível em:

    http://localhost:3000

### Build de produção

    npm run build
    npm run start
